AnonGate ceremony contributor kit (Phase 2)

Needs: Windows laptop + Node.js LTS from https://nodejs.org
First run: 15–40 minutes (install + four files). Leave the window open.

1) Unzip this folder
2) Double-click run.bat
3) Enter a name or nickname
4) Enter a random sentence of at least 20 characters
   That sentence is secret. Do not send it in chat.
5) Wait for DONE (four files)
6) Send only the out folder (four .zkey files + hashes.txt)
7) Delete the large folder from your machine after you send it

Do not send anything except the out folder.
Do not send the random sentence.
Do not send console screenshots.
Do not send the input folder.

If you see "Random text is too short", run run.bat again with a longer sentence.
If npm install fails because of the network, run run.bat again.
